# ⚡ DeFi Pulse Dashboard

A high-performance, real-time decentralized finance (DeFi) analytics & protocol dashboard with live TVL tracking, chain dominance, and staking yield opportunities.

## 🚀 Features
- **Live On-Chain Data:** Powered by DefiLlama API (100+ protocols, multi-chain breakdown).
- **Interactive Charts:** Recharts historical TVL growth and blockchain dominance.
- **Yield & Staking Explorer:** Filterable high-yield liquidity pools & stablecoin staking.
- **Mobile-First Responsive Design:** Ultra-fast, dark glassmorphism aesthetic optimized for mobile & desktop.
- **Automated Deployment:** Dockerized with Nginx reverse proxy.
